# Security Policy

## Reporting a vulnerability

请不要在公开 Issue 中披露安全或隐私漏洞，也不要上传真实 Codex 日志、数据库、会话内容、
凭据或机器路径。

请通过 GitHub 仓库的 **Security → Report a vulnerability** 私下提交报告。报告应尽量只包含：

- 受影响版本；
- 可复现的最小合成样例；
- 预期行为与实际行为；
- 影响范围；
- 不含真实用户数据的修复建议或补丁。

维护者会确认报告、评估影响，并在修复可安全发布时协调披露。

## Supported versions

当前仅维护 GitHub Releases 中的最新版本。
