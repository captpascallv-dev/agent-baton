# Format

The layout, fields, and access rules are in `docs/data-format.md` in the Onestead repository. That document is the authority. This page does not restate them.

A project may include `paths`: absolute directories on the computer that runs Onestead. When an agent starts in one of those directories, `company()` leads with that project's current status. Remote connections do not match by directory.
