CLI Watch source distribution

This directory contains a separately maintained fork of a local Telephone
cockpit UI. Source files retain their Mozilla Public License 2.0 terms.
The original license and the retained .NET license/third-party notices are
included under LICENSE and src/licenses/.

The October 2026 agent-baton distribution uses generic CliWatch namespaces,
portable configuration and launch/build scripts, and supports the public
agent-baton task directory format. The source tree contains no original
repository history, personal runtime records or compiled dependencies.
Separately published Windows portable packages include the .NET runtime
and retain its notices under licenses/.
